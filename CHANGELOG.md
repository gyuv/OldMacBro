# Changelog

All OldMacBro releases. Download any version from the **[Releases page](https://github.com/gyuv/oldmacbro/releases)**.

From v1.6.0: Mac DMG + portable zip for Intel and Apple Silicon, and Windows Setup + portable zip. From v1.4.0: an Intel and an Apple Silicon DMG. Up to v1.3.0: Intel (x86_64) only. All need macOS 12 or newer and are ad-hoc signed (on first launch, right-click **OldMacBro.app** and choose **Open**).

## v1.8.0 · 2026-10-13
- **Mac: Date & Time repair.** Detects a clock that reset after the battery drained, fixes it with one click, and can re-sync automatically at every startup.

## v1.7.0
- **Windows: "Why is it slow?"** diagnosis (disk type and health, disk hogs, memory leaks, antivirus, OneDrive, dead network drives, slow folders) and one-click **Revive this PC**.

## v1.6.x
- **Auto-update** on Mac and Windows: background download, one restart to apply.
- **Portable zips** for Intel and Apple Silicon Macs, and a full **Windows Setup** installer.
- Windows fixes: Tools crash, touchpad scrolling, faster Disk Space analyzer, working System File Check with live progress.

## v1.5.0
- **New: OldMacBro for Windows & Windows Server.** Portable, optimises every user on the machine in one run; premium UI with live progress, multi-select and select all.

## v1.4.0 · 2026-10-06
- **New: Apple Silicon edition.** Native arm64 build for M1–M4 Macs with P-core/E-core readings, M-series sensors, fanless-aware Thermals, Rosetta detection in Smart Boost and an Intel-only apps filter in the Uninstaller.
- Every release now ships two DMGs (`-Intel` and `-AppleSilicon`) plus `SHA256SUMS.txt`.
